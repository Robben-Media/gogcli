# Triage labels

The canonical Matt Pocock triage roles map directly to GitHub labels in this repository.

| Role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer or autonomous triage must evaluate the issue |
| `needs-info` | `needs-info` | Essential information is missing |
| `ready-for-agent` | `ready-for-agent` | Verified, fully briefed, and ready for `/implement` |
| `ready-for-human` | `ready-for-human` | Valid work requiring human judgment or execution |
| `wontfix` | `wontfix` | Will not be implemented |

Every triaged issue has exactly one category label (`bug` or `enhancement`) and one state label from this table. Additional provenance labels such as `codex-automation` do not count as state.
