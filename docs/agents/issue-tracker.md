# Issue tracker: GitHub

Issues and specs for this repository live in `Robben-Media/gogcli` GitHub Issues. Use the `gh` CLI for tracker operations and confirm that the repository inferred from `git remote` is `Robben-Media/gogcli` before writing.

## Conventions

- Create one issue per bounded piece of work.
- Read the complete issue body, comments, labels, author, and dates before changing triage state.
- Search open and closed issues and merged pull requests by domain concept before creating or advancing an issue.
- Use issue comments for triage notes and durable agent briefs; do not rewrite the original report into a second source of truth.
- Pull requests are not a triage request surface.

Generated ideas carry `codex-automation` for provenance. That label does not imply readiness: only the triage state label determines whether an issue can be implemented. The local global-triage automation also reads eligible issues from other repositories owned by `Robben-Media` and `itsjeremyjohnson`; this document governs only `Robben-Media/gogcli` itself.
